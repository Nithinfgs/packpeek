# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful. Assume good faith, and critique code and ideas, not people.
- No harassment, discrimination, personal attacks, or unwelcome sexual attention.
- Do not publish other people's private information.
- Maintainers may edit, hide or remove comments, issues and contributions that violate this, and may block repeat offenders.

## Reporting

Report conduct problems to the maintainer, [@Nithinfgs](https://github.com/Nithinfgs), by opening a private security advisory titled "Conduct report" at <https://github.com/Nithinfgs/packpeek/security/advisories/new>, which is not public. Reports are handled confidentially.
